# v0.11.3 — 大厅界面修复

- 改名按钮只在大厅显示，进入战斗时同步隐藏，返回大厅后恢复；大厅组件销毁时清理按钮，避免跨局残留。局内 F2 不再打开改名窗口。
- 非房主右下角按钮显示“准备”，准备后显示“取消准备”。房主保留独立的“开始游戏”按钮。
- 附带的 Windows 房主程序同步此前 ECS 热修复：无人在线时回收空对局、保持监听；爆炸范围伤害可伤及引发者，自杀不计击杀数。

内部版本为 `0.11.3.0`。本次大厅界面改动需要更新客户端，关闭游戏后重新打开启动器即可更新。ECS 服务端热修复已部署，本次不重启正式服务。

已在本机两个实际 Unity 进程中检查房主/非房主准备文字、开局、局内改名按钮与 F2 隐藏、回合结束返回大厅后入口恢复。使用隔离本机服务，未重跑完整物理双机故障矩阵；此前披露的其他已知问题仍保留。
