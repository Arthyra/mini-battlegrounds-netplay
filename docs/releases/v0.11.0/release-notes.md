# v0.11.0 — ECS Stable

ECS 公网联机的稳定版。本版本与此前 0.10.x 的玩法内容一致，重点是**联机稳定性、自动更新可靠性与长期可游玩性**。

## 联机稳定性
- 战斗断线自动重连：TCP 重连 → 战斗快照重放 → UDP 重新注册，恢复后可继续移动/开枪/受伤/倒地/复活/上下车
- 加载期断线不误触发结束回合，恢复后正常进图
- 断线时重置开镜/乘车等瞬态状态，避免重连后位置被钉住
- 服务器宕机时客户端安全退出到登录界面（不再崩溃），服务器恢复后自动重新登录
- 服务端 15 秒静默检测：黑障链路不再留下僵尸连接
- 修复重登录丢失房主、修复乘车玩家状态同步崩溃（vehicle.y）

## 自动更新
- 全部走 HTTPS：RSA 证书链（ISRG Root X1）+ ECDSA 备用 + 旧 HTTP 兼容入口，每个入口都强制 RSA-SHA256 签名校验
- 更新包 SHA256 强制校验，篡改/损坏一律拒绝
- 自动清除网络下载标记，首次运行后不再重复弹"无法验证发布者"
- 更新流程无点击化：启动器退出 → 更新器安装 → 自动重启
- 证书自动续期（独立于其他服务）

## 玩法修复（继承 0.10.x）
- 开镜关镜、上下车后移动立即恢复
- 击杀榜、20Hz 状态同步、乘车朝向同步、丢包率显示、UDP 诊断 HUD
- 阴影质量重构，消除间歇性斑驳黑块

## 验证
- ECS 双真实客户端同场：登录/开局/双向位置同步/命中/倒地/复活 全部通过
- 协议回归（登录/开局/UDP 中继/断线重连/乘车状态/断线重置）多轮 PASS
- 10 轮连续对局无内存/fd 泄漏

已知限制：首次从浏览器下载后运行会弹一次安全警告（点"运行"即可，无代码签名证书）；黑障网络下的客户端 8 秒心跳未在真实防火墙环境实测。
