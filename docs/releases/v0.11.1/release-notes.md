# Mini Battlegrounds ECS v0.11.1

改进 ECS 断线恢复与自动更新可靠性，保留现有地图 102 复活玩法。

- 修复 TCP 正常关闭后残留 CLOSE_WAIT、登录可能一直等待的问题；断线前的完整消息仍会派发，残缺尾包会清理。
- 战斗 TCP 改为异步连接，避免连接等待阻塞 Unity 主线程；入场响应增加超时，连续失败保留重试计数和次数上限。
- 修复战斗结束后心跳访问空代理，以及旧服务端连接误取消新连接 UDP 告警任务的问题。
- 新启动器仅通过 HTTPS 获取清单和下载更新，保留 RSA-SHA256 签名与 ZIP SHA256 校验。旧启动器的 HTTP 清单兼容入口继续提供服务，下载地址指向 HTTPS。
- 安装更新前检查文件占用，安装失败时回滚；不再批量清除 Windows 下载安全标记。

## 版本与安装

发布名称为 v0.11.1，启动器及更新清单内部版本为 **0.11.1.10**，确保 0.11.1.9 候选版也可升级。完整解压 ZIP 后运行 `Start Game.exe`，连接正式 ECS。正式包不包含测试端口覆盖或断网验收工具。

## 已有验证与已知限制

已完成实际 DLL 的完整/残缺 TCP EOF 回归、连接与重试状态测试，以及两进程真实 Unity 对隔离 ECS 的进图、空闲心跳和双方分别硬断线恢复检查。更新签名/损坏包拒绝、安装占用/回滚已有验证；v0.10.9、v0.11.0 测试副本完成更新与自动重启流程。

**按用户明确决定发布，剩余双物理 Windows 复测已取消，并不代表这些项目测试通过。** 原定的 10 轮物理双机恢复、Windows 防火墙 TCP 黑洞、加载/UDP 故障完整矩阵未完成；v0.10.8 全流程自动重启及下载中断测试也未完整验证。

此前实机发生过重载地图后人行道亮网格，根因尚未确认，最新本机诊断复测暂未重现。第二台电脑曾出现非人为掉线，已据日志修复连接清理与等待状态缺陷，但初始流量中断原因仍未完全确定。不要将本版本视为已经完成长期稳定性全项验收。
